============================================================
ComfyUI Eclipse Workflow Migration Node Name Mapping
============================================================

If your existing ComfyUI workflows fail to load or show red missing nodes after upgrading to Eclipse v4.0.0, you can fix them easily. 

We have provided a migration script in the repository that automatically processes single files or directories of workflows and creates backups:
```bash
python tools/migrate_workflow.py <path_to_workflow.json_or_directory>
```

For older name-only changes, the mappings below describe the node type fields to update.
Do not replace matching words inside prompts, notes, or custom titles.

Deprecated Eclipse nodes -> ComfyUI built-ins (use the tool, not text replacement):
  Integer [Eclipse]          -> PrimitiveInt
  Boolean [Eclipse]          -> PrimitiveBoolean
  String [Eclipse]           -> PrimitiveString
  String Multiline [Eclipse] -> PrimitiveStringMultiline
  Show Text [Eclipse]        -> PreviewAny

The tool adapts socket names and widget values, keeping Int fixed after generation.
A connected standard multiline input becomes value and replaces local text.
Two connected multiline inputs require manual review and are left unchanged.
String Multiline List and Show Text Stop are not converted.
Universal Block Swap has no direct built-in replacement and remains in Legacy.
These deprecated nodes still load in existing workflows; conversion is optional.
The tool preserves earlier backups by numbering additional .bak files.

1. Smart Model Loader
------------------------------------------------------------
Old Node Type ID:   "Smart Model Loader v2 [Eclipse]"
New Node Type ID:   "Smart Model Loader [Eclipse]"

Search & Replace in JSON:
Find:    "Smart Model Loader v2 [Eclipse]"
Replace: "Smart Model Loader [Eclipse]"

4. Pipe IO Sampler Settings
------------------------------------------------------------
Old Node Type IDs:  "Pipe IO Sampler Settings v2.1 [Eclipse]"
                    "Pipe IO Sampler Settings v2.2 [Eclipse]"
                    "Pipe IO Sampler Settings v2.3 [Eclipse]"
These IDs remain registered as deprecated Legacy nodes. Keep them unchanged:
they retain upscale_steps, upscale_denoise and prompt_seed in their original
socket order. Renaming them to the current unversioned node can redirect links
to different outputs.

------------------------------------------------------------
5. Smart Sampler Settings
------------------------------------------------------------
Old Node Type IDs:  "Smart Sampler Settings v2 [Eclipse]"
                    "Smart Sampler Settings v3 [Eclipse]"
New Node Type ID:   "Smart Sampler Settings [Eclipse]"

Search & Replace in JSON:
Find:    "Smart Sampler Settings v2 [Eclipse]" or "Smart Sampler Settings v3 [Eclipse]"
Replace: "Smart Sampler Settings [Eclipse]"

On normal JSON/image import, recognized older layouts with separate upscale
steps/denoise automatically use Smart Sampler Settings (Legacy). This also
covers older workflows saved under the unversioned name. Keep that Legacy
node when its separate upscale channels are required.
